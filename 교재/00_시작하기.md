## 학습 목표

- `uv` 로 컴퓨터 비전 실습 환경을 1분 안에 준비한다.
- 왜 `opencv-contrib-python` 을 써야 하는지 이해한다.
- 실습 에셋을 내려받고 카메라 동작을 확인한다.

## 컴퓨터 비전이란

컴퓨터 비전은 카메라로 들어온 이미지에서 의미 있는 정보(색, 모양, 얼굴, 움직임)를
컴퓨터가 읽어내는 기술입니다. 이 특강에서는 파이썬 라이브러리 **OpenCV** 로
색 인식 게임, 얼굴 인식 출입 시스템, 움직임 감지 보안기를 직접 만들며 배웁니다.

## 1. 저장소 받기

```bash
git clone https://github.com/sung2ne/2026_cv_practice.git
cd 2026_cv_practice
```

## 2. 패키지 설치

이 특강은 빠른 패키지 관리자 `uv` 를 씁니다. 저장소에 `pyproject.toml` 과
`uv.lock` 이 들어 있어 아래 한 줄이면 모두 같은 버전으로 설치됩니다.

```bash
uv sync
```

설치되는 핵심 라이브러리는 `opencv-contrib-python` 입니다.

> 주의할 점이 하나 있습니다. OpenCV 에는 `opencv-python` 과 `opencv-contrib-python`
> 두 가지가 있는데, 얼굴 인식(`cv2.face`)과 68점 랜드마크 기능은 contrib 버전에만
> 들어 있습니다. `opencv-python` 을 설치하면 2일차 실습에서 오류가 납니다.
> `uv sync` 를 쓰면 올바른 contrib 버전이 자동으로 설치됩니다.

## 3. 실습 에셋 내려받기

샘플 이미지와 모델 파일(얼굴 검출기, 랜드마크 모델)을 한 번만 내려받습니다.

```bash
uv run 00_asset_downloader.py
```

`data/images/` 와 `data/models/` 폴더에 파일이 저장됩니다.

## 4. 환경 점검

```bash
uv run 01_env_check.py
```

아래처럼 나오면 준비 완료입니다.

```
cv2.face (contrib) : OK
카메라 : 연결됨 (index 0)
```

`cv2.face` 가 "없음" 으로 나오면 잘못된 패키지가 설치된 것입니다. 안내 메시지대로
`opencv-contrib-python` 으로 다시 설치하세요. 카메라가 안 잡히면 노트북 웹캠 연결과
운영체제의 카메라 권한(맥은 터미널 권한)을 확인합니다.

## 실행 방법 요약

각 실습은 해당 폴더로 이동해 `uv run` 으로 실행합니다. 대부분 웹캠 창에서 `ESC` 로 종료합니다.

```bash
cd 03_color_bingo_game
uv run main.py
```

## 직접 해보기

- `01_env_check.py` 를 실행해 본인 노트북의 OpenCV 버전과 카메라 인덱스를 확인해 봅니다.
- 카메라가 여러 개라면 코드의 `cv2.VideoCapture(0)` 에서 숫자를 1로 바꿔 시도해 봅니다.
