- 생성일시: 2026-06-21 17:18
- 수정일시: 2026-06-21 17:18

2026년 6월 24일~26일 "OpenCV를 활용한 컴퓨터 비전 인식 기술" 특강 교재입니다.
(경남정보대학교 공학기술교육혁신센터)

이 교재는 두꺼운 이론서가 아니라, **3일간 손으로 만들면서 배우는 실습 안내서**입니다.
각 장은 이 저장소의 실습 코드와 1:1로 연결됩니다. 코드 전체는 각 폴더에 있으니, 교재는
"무엇을·왜·어떻게 실행하는지"에 집중합니다.

## 사용법

1. 먼저 [`00_시작하기`](00_시작하기.md) 로 개발 환경을 준비합니다.
2. 강의 순서대로 한 장씩 읽으며 해당 폴더의 코드를 `uv run` 으로 실행합니다.
3. 각 장 끝의 "직접 해보기" 로 값을 바꿔보며 원리를 체득합니다.
