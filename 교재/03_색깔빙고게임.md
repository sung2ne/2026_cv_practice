## 학습 목표

- 앞에서 배운 HSV 색 검출을 실시간 게임으로 완성한다.
- 코드를 설정·로직·화면으로 나누는 구조를 경험한다.
- 임계값을 조절해 현장 조명에 맞게 튜닝한다.

## 게임 규칙

웹캠 앞에 9가지 색의 물건을 비춰 3×3 빙고판을 채웁니다. 가로·세로·대각선 중
한 줄을 완성하면 "빙고!". 색을 인식할 때마다 점수가 오릅니다.

## 코드 구조

큰 프로그램은 역할별로 파일을 나누면 이해하고 고치기 쉽습니다.

- `config.py` — 9가지 색의 HSV 범위와 게임 설정(제한 시간, 검출 임계값)
- `game.py` — 게임 규칙(색 검출, 빙고 판정, 점수). 화면 코드는 없음
- `ui.py` — 한글 글자를 화면에 그리는 도우미
- `main.py` — 웹캠을 읽어 위 셋을 엮는 실행 진입점

## 핵심 1: 색 정의 (config.py)

```python
COLORS = {
    "빨강": {"range": [((0, 90, 80), (10, 255, 255)), ((170, 90, 80), (180, 255, 255))], "bgr": (0, 0, 255)},
    "파랑": {"range": [((97, 90, 70), (128, 255, 255))], "bgr": (255, 0, 0)},
    ...
}
```

각 색은 HSV 범위 목록(`range`)과 화면 표시색(`bgr`)을 가집니다. 빨강은 H 가
양 끝에 걸쳐 범위가 두 개입니다.

## 핵심 2: 색 검출과 빙고 판정 (game.py)

```python
def detect_color(self, frame):
    hsv = cv2.cvtColor(frame, cv2.COLOR_BGR2HSV)
    best, best_count = None, DETECTION_THRESHOLD
    for name in self.board:
        if self.found[name]:
            continue
        count = self._mask_count(hsv, name)   # 그 색 픽셀 수
        if count > best_count:
            best, best_count = name, count    # 가장 많이 보이는 색 선택
    if best:
        self.found[best] = True
        ...
```

화면에서 아직 못 찾은 색 중 **가장 많이 보이는 색** 을 골라 찾은 것으로 표시합니다.
`DETECTION_THRESHOLD`(기본 1500픽셀)보다 많아야 인정되므로, 작은 색 점에는 반응하지
않습니다. 빙고 판정은 3×3 의 8개 줄을 검사해 한 줄이 다 채워졌는지 확인합니다.

## 직접 해보기

- 조명이 어두워 색이 잘 안 잡히면 `config.py` 의 `DETECTION_THRESHOLD` 를 낮춥니다.
  반대로 아무 색이나 너무 쉽게 잡히면 값을 높입니다.
- 특정 색(예: 주황)이 잘 안 잡히면 그 색의 H 범위를 조금 넓혀 봅니다.
- 9가지 색 중 하나를 본인이 가진 물건 색으로 바꿔 새 범위를 직접 정해 봅니다.

> 참고: 처음에는 9번째 색으로 "검정" 을 썼지만, 검정은 그림자·어두운 배경에 계속
> 오검출되어 "연두" 로 바꿨습니다. 색의 종류(H)로 구분되는 색이 무채색(검정·흰색)보다
> 훨씬 안정적으로 검출됩니다.
